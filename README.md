# КРЕМЕНЬ · Kremen (NexusTune)

**[Русский](#русский) · [English](#english)**

> 🌐 **Язык интерфейса: только русский** · **Interface language: Russian only**

Приложение для оптимизации игрового ПК под Windows — чистит мусор, отключает лишнее, тюнит систему под максимум FPS. С графическим интерфейсом и «экспертным» режимом.

A gaming-PC optimization app for Windows — cleans junk, disables bloat, tunes the system for maximum FPS. Has a GUI and an "expert" mode.

---

## Русский

### Что это
КРЕМЕНЬ (бывш. NEXUS TUNE) — настольное приложение, которое ускоряет игровой ПК: отключает телеметрию/лишние службы, чистит кэши, применяет игровые твики, показывает состояние системы.

### Возможности
- 🧹 Очистка временных файлов и кэшей
- ⚡ Игровые твики (план питания, GPU, Game Mode)
- 🔇 Отключение телеметрии и ненужных служб
- 📊 Мониторинг системы
- 🧠 «Экспертный» режим с рекомендациями
- 📦 Сборка в один EXE (для друзей)

### Требования
- Windows 10/11
- Python 3.12 (или готовый EXE)

### Запуск
- `Запустить КРЕМЕНЬ.bat` — запуск из исходников
- `Установить зависимости.bat` — поставить библиотеки
- `Собрать EXE для друзей.bat` — сборка автономного .exe

## English

### What it is
Kremen (formerly NEXUS TUNE) is a desktop app that speeds up a gaming PC: disables telemetry/unneeded services, cleans caches, applies gaming tweaks, and shows system status.

### Features
- 🧹 Cleans temp files and caches
- ⚡ Gaming tweaks (power plan, GPU, Game Mode)
- 🔇 Disables telemetry and unnecessary services
- 📊 System monitoring
- 🧠 "Expert" mode with recommendations
- 📦 Build into a single EXE (to share)

### Requirements
- Windows 10/11
- Python 3.12 (or the prebuilt EXE)

### Run
- `Запустить КРЕМЕНЬ.bat` — run from source
- `Установить зависимости.bat` — install libraries
- `Собрать EXE для друзей.bat` — build a standalone .exe
